Tags

A tag is a status word on a thing. A badge is a count on a control. Neither can be pressed, so neither is round.

01

Variants

Tags take the system's tones: none, ink, or 1 to 6. The badge has one look: an ink square with a number in it.

1.1

Tag

Where a card stands: known, new, due, not yet.

.tag

A square 2px frame around one or two words in label type. The markup stays sentence case ("Not yet"); the capitals are CSS, so a screen reader says the words, not the letters. It replaced the wireframe kit's stand-in.

1.2

Ink

The one status on the screen that has to be seen first.

data-tone="ink"

The surface's ink and fill swap, so on an ink card it turns paper instead of vanishing. Use it sparingly: if every tag is ink, none is.

1.3

Tones

Six grey fills, 1 the quietest, in either scheme.

data-tone="1" … "6"

Rhythm, not meaning. The word says "Due"; a tone never says it alone. Text and frame take the slot's own ink, --on-tone-N.

1.5

Badge

How many are waiting behind a control.

.badge aria-hidden

At least 20px, ink, tabular figures, and "99+" past 99. Pinned to the corner of an icon button; after the label in a text button. The badge is aria-hidden: the count is in the control's name, so it is heard as "Decks, 7 due".

02

States

None of their own: no hover, focus or press, because neither acts. A tag changes with the surface under it; a badge changes with its count, and follows its control's state.

03

Usage

  1. Do

    Use the product's own status words, one or two: Known, New, Due, Not yet. Put the true count in the control's name and cap only what's drawn.

  2. Don't

    Don't make a tag pressable. A filter is a toggle button or a segmented control. Don't let a tone carry a status on its own, and don't badge something that has no count.

  3. Installed PWA

    The home-screen badge is the system's, set through the Badging API (wave 5). It and the in-app badge show the same number.

  4. Mac and SwiftUI

    A tag is Text in the label style with a square strokeBorder. A system tab or sidebar row takes the system .badge(_:); our own controls draw this one, with the count in .accessibilityLabel.
