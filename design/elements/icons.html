Icons

Twenty-six glyphs, drawn as line work on the frame's own weight: a 24 grid, a 2px stroke with square ends, no fills. They take the colour of the text around them.

01

The set

Each glyph at 48, 24 and 20px. The 48 is there to show the drawing; 20px (--ic-size: 1.25rem, the default) and 24px are the sizes in use. Every one is a --icon-* token and an .ic--* class; the path data, for native apps, is in icons.md.

1.1

Navigation

Moving around inside the app.

.ic--back .ic--forward .ic--down .ic--up

Chevrons, not arrows: they move you within the app, and ↗ is kept for leaving it. Back sits in the top bar with the previous screen's name; forward ends a row that opens a screen.

1.2

Actions

Something you do to the thing on screen.

.ic--more .ic--search .ic--edit .ic--delete .ic--share .ic--undo .ic--refresh .ic--shuffle .ic--flip .ic--install .ic--sidebar

Each one is the glyph for one verb, so it never changes meaning between screens. Delete always has words beside it ("Delete deck"). Share is also where iOS keeps Add to Home Screen.

1.3

Status

News about the app or a field.

.ic--info .ic--warning .ic--offline

Always next to words: "You're offline. Changes are saved on this device." The glyph is a second cue, never the only one. Drawn a little larger than the square glyphs, because a circle and a triangle look smaller at the same width.

1.4

Places

The tab bar and the sidebar.

.ic--settings .ic--today .ic--decks

Settings is a pair of sliders, not a gear: at 20px a gear's teeth close up into a blob, and sliders stay two clean lines. Decks is a stack of cards. In a tab bar the label always sits beside the glyph.

1.5

Kept from v0

The first five, unchanged.

.ic--arrow .ic--plus .ic--minus .ic--close .ic--check

Same class names, same drawings. ↗ (arrow) means "leaves the app", on the web and on Apple platforms, so it never marks an in-app link.

02

In use

A glyph has no states of its own: it takes currentColor from the control or the text it sits in, so it follows them through hover, press, the inverted tone and forced colours.

2.1

Two sizes

20px beside text, 24px on its own.

--ic-size

20px (1.25rem) is the default: in fields, lists and beside a label. 24px (1.5rem) where the glyph stands alone in a bar. Both are rem, so they grow with the reader's text size. Never smaller: under 20px the 2px line closes up.

20px. --ic-size: 1.25rem, the default.

24px. --ic-size: 1.5rem, standing alone.

2.2

Inline with text

A glyph inside a sentence.

--ic-size: 1.25em

Sized in em so it follows the line, and lowered by vertical-align: -0.25em so it centres on the capitals. Inside a flex row (a control, a field) none of this is needed: align-items: center does it.

To install it, tap Share, then Add to Home Screen.

2.3

In a control

A glyph is the whole visible label.

aria-label aria-hidden

The control carries the name ("Share Shapes"); the glyph stays aria-hidden. The target is 44px whatever the glyph's size. Shown in Button's icon-only control, and in the card's own slot, the 44px action circle.

2.4

Ink and forced colours

Any ground, any theme.

currentColor CanvasText

On the inverted tone a glyph is paper because its text is. In forced colours (Windows contrast themes) backgrounds are dropped, and a mask glyph is a background, so icons.css paints every glyph in CanvasText there, in every state. No glyph needs colour to read, so nothing else changes.

03

Usage

  1. Do

    Mark every glyph aria-hidden="true": it is decoration. When a glyph is a control's only content, name the control with aria-label. Pair status glyphs with words.

  2. Don't

    Don't put a glyph in a tinted circle, or repeat one on every card in a grid. Don't use ↗ for an in-app link. Don't fill or tint a glyph to make it mean something.

  3. Installed PWA

    No browser chrome, so back is always on screen. iOS keeps Add to Home Screen behind its Share sheet: install instructions show the share glyph. Chromium's prompt gets the install glyph.

  4. Mac and SwiftUI

    Native toolbars and menus use SF Symbols; these are for what we draw. In SwiftUI each glyph is a Path on the 24 grid, stroked with lineWidth: 2 and lineCap: .square.
