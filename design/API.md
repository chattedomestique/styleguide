### Layers

`css/flashcards.css`: `@layer tokens, base, components, wire, app, sheet;`. Later wins. [STYLE.md §2 Files and layers](STYLE.md#files-and-layers).

| Layer | Files | What |
| --- | --- | --- |
| `tokens` | `tokens/foundation.css` `tokens/color.css` | values and roles. No selectors except :root and [data-tone]. |
| `base` | `base.css` `icons.css` | reset, element defaults, type styles (.t-*). |
| `components` | `components/card.css` `components/button.css` … 26 files | one file per element. Reads roles only, never a raw colour. |
| `wire` | `wire.css` | wireframe placeholders (.wf-*). Disposable: each one is deleted when the real element ships. |
| `app` |  | your app's own CSS. Put it here: unlayered CSS beats every layer, so it would silently override card states. |
| `sheet` |  | the style-sheet page's own chrome. Not shipped to the app. |
| (none) | `fonts.css` | `@font-face`, outside the layers |

**App CSS goes in `@layer app`.** Unlayered CSS beats every layer and would override the components' states.
