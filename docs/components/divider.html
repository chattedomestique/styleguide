Components

Divider

A line that separates, and can say what comes next. It is flat and static: it never lifts, never has a shadow, and takes the colour of the text around it, so the same divider is ink on a card and paper on an inverted one.

When to use

Do

Use space first and a divider when space is not enough to show that two groups are different: a choice between two ways in, a day in a history, two kinds of action in a toolbar.

Don't

Rule between every line, or use a divider inside a List (its rows already have rules) or a card foot (it has one). Do not count on the quiet divider to mark a boundary: it is decoration.

Rules

A bare <hr> with the class. One line weight per job, as everywhere in this guide: 1px divides, 2px is a frame weight and marks a bigger break. data-quiet uses the faint line colour, for decoration that must stay out of the way.

Thin: the default. Between two kinds of thing in one card.

Frame weight: a section break.

Quiet: decoration only.

On an inverted card

The line is paper on an inverted card, because it is currentColor: the same divider, no role to pick.

Today

Twelve cards to review

Next session is at 18:00.

Labelled

Text between two rules. The lines are drawn by ::before and ::after, so the label is ordinary text: a screen reader says it, which it would not do for a label inside a role="separator" (whose children are presentational). The label is uppercase structure (--type-label), written in natural case.

or

A divider that names a group

If the label names the group below it (a day, a month, a category), make the element a heading at the right level. It is then in the page outline, and a screen-reader user can jump between the groups. data-align="start" puts the label first and draws only the far rule; every group of one list uses the same alignment.

Today

Sports outlet−$734.00
Metro card top-up−$20.00

Yesterday

Salary+$3,200.00

Earlier in April

Electric bill−$62.40

data-align="end" puts the label last. It suits a label that sums up what is above it and lines up with the values at the end, such as a total under a column of amounts. Keep the amounts on that edge at every text size: these rows do not wrap (flex-wrap: nowrap), so a long name wraps beside its amount instead of the amount dropping under the name, away from the total. A total that cannot keep its rule beside it takes the rule on a line of its own, above it.

Electric bill−$62.40
Water bill−$31.10

Total −$93.50

Vertical

Between siblings in a row. It stretches to the row's height (so the row needs to be flex or grid) with a 24px minimum. A bare <hr> keeps its separator role; set aria-orientation to vertical only when it really separates controls in a toolbar. The row never wraps, because a wrapped row would start or end a line with a rule that separates nothing: when it cannot fit one line (a phone at large text), a few lines of script (src/js/48-divider.js) turn it into a column, with the rules lying flat between the items. Raise the text size to see it.

Settings

Anatomy

  1. Rule: border-block-start of --bw-thin (or --bw for the frame weight, data-weight frame) in currentColor. A border, not a background, so forced-colours mode still draws it.
  2. Label (optional): --type-label, uppercase, positive tracking, wraps at large text. Aligned to a side, a label that cannot keep its rule beside it takes the rule on a line of its own, full width: under a start label, over an end label.
  3. Side rules (labelled): ::before and ::after, each growing to fill. Aligned to a side, the near one is not drawn.

API

Divider attributes
AttributeValuesEffect
class="divider"On an <hr> for a plain rule; on a <p>, <div> or heading for a labelled one.
data-weightframe (default thin)1px or 2px.
data-quietThe faint line colour (--line-soft). Decoration only.
data-alignstart, end (default centre)Where a labelled divider puts its label.
data-orientationverticalA vertical rule for a row. Its row stays one line, or becomes a column with the rules lying flat (measured by src/js/48-divider.js).

Accessibility

Divider keyboard and screen reader behaviour
InteractionBehaviour
TabNot focusable.
Screen readerA bare <hr> is a separator. A labelled divider is its text ("or", "Yesterday"); as a heading, it is announced and navigable as one.
ColourThe rule is currentColor, so it has the contrast of the text around it (7:1). The quiet rule is 3:1 and is decoration, never the only boundary.
Zoom / text sizeLabel wraps; a centred label keeps at least 12px of rule on each side, and a label aligned to a side takes its rule on a line of its own when it cannot keep it beside, so the rule is never a stub away from the words. A row with vertical rules becomes a column when it cannot fit one line, so a rule never starts or ends a line.
Reduced motionA divider does not move.
Forced coloursRules are borders in CanvasText, so they survive.
