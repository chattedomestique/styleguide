Components

Donut chart

A donut shows how a whole divides: where the month's money went. Five parts at most, the total in the middle, and a legend that says each part's name and value in words, because the ring itself has no labels.

When to use

Do

Use it for a whole with three to five parts that add up to something meaningful. Keep the legend beside it with the values printed. Fold the tail into "Other".

Don't

Use it to compare two close parts (angle is hard to read: use a bar chart), draw more than six sectors, or show a single percentage (that is a number or a meter).

Examples

With a legend

The ring sits at 11rem and grows with text size. The container decides the layout: stacked on a phone, ring-and-legend side by side from 32rem. Each sector is a tone and a pattern, told apart without colour; the 2px frames between sectors carry the edges.

In a card

On a Card panel. The total moves to the hole, the legend keeps the values. The same markup, narrower.

April

Two parts: spent and left

Two sectors make a progress ring. Keep both named: "Spent" and "Left" are words, and the hatched sector is the one that is used up. If the only question is how far along something is, a <meter> says it more plainly.

One part

A single part fills the ring. It is drawn as one closed outline (an outer circle and the hole), so the frame has no seam that would suggest two parts. It is the edge case the helper covers, not a design to aim for.

From data

SG.chart.donut(items, { label }) returns the whole <svg>: the sectors, the pattern tiles it needs and the text alternative. Pass the legend and the total as ordinary markup beside it. This page runs the code below on the empty .donut__body of the chart under it (el), so the ring you see is what the helper returns.

const items = [
  { label: 'Rent',
    value: 620, tone: 1 },
  { label: 'Food',
    value: 284, tone: 2 },
  { label: 'Transport',
    value: 152, tone: 3 },
]
const label = [
  'Essentials in April,',
  '$1,056 in total:',
  'rent 59%, food 27%,',
  'transport 14%.',
].join(' ')
const ring = SG.chart
  .donut(items, { label })
el.insertAdjacentHTML(
  'afterbegin', ring)

Anatomy

  1. Title (.donut__title): names the chart. Hide it with sr-only when a Card bar already says it.
  2. Ring (.donut__ring): an SVG with role="img" and a label that lists the parts and the total. 176 units = 11rem, so one unit is one pixel at the default text size.
  3. Sector (.donut__seg with .donut__fill, and .donut__pat for tones 2 to 6): the tone fill, the pattern on top, a 2px frame that stays 2px at any size.
  4. Hole (.donut__centre): the total and a one-word caption, as HTML text, so it scales with the reader's text size and is read as text.
  5. Legend: one row per sector with its value and share. It is the readable form of the chart.

API

Donut chart classes and helpers
HookValuesEffect
.donuta figureThe chart and its size container.
.donut__layoutStacks the ring over the legend; puts them side by side from 32rem of width.
.donut__bodyThe 11rem square that holds the ring and the hole text.
.donut__segdata-tone="1" to "6" on a <g>One sector. Tone 1 is solid; 2 to 6 add the pattern path with fill="url(#id-pN)".
SG.chart.donut(items, opts)items: [{ label, value, tone }], opts: { label, id, size, outer, inner }Returns the <svg> string. label is required: a donut with no text alternative is refused. id keeps the pattern ids unique on the page.
SG.chart.arcs(values, opts)[{ d, start, end, share }]Just the sector paths, if you draw the rest yourself.

Accessibility

Donut chart keyboard and screen reader behaviour
InteractionBehaviour
TabNothing to reach. A static chart takes no focus and offers no hover-only detail.
Screen readerThe ring is one image whose label gives the total and every part with its share. The legend is a list of the same values as text. The hole's total is ordinary text.
ColourSectors differ by pattern as well as tone (WCAG 1.4.1) and each has a 2px frame for the 3:1 edge (1.4.11). The legend names them.
Zoom / text sizeThe ring is in rem and shrinks only when its container does. The hole text is HTML, so it scales; the ring is big enough at 200% (22rem) to keep it inside.
Reduced motionNothing moves: the ring does not sweep in.
Forced coloursFills go; frames and patterns are drawn in system colours, so the parts still differ.
