Components

List

Rows, ruled by 1px lines: a settings screen, a history, a list of decks. And the key / value grid for facts about one thing. Both are flat containers: rectangles hold, so nothing here lifts or casts a shadow. A row you can press tints instead, and inverts when it is the current one.

When to use

Do

Keep one job per row: it opens something, or it shows something, or it holds one control. Put the name first and the value or the chevron at the end.

Don't

Put a button inside a row that is itself a link, or use rows for a grid of equal things (that is tiles or cards). A row with two actions is two rows, or a row that opens a page.

Ruled rows

A <ul class="list" role="list"> of <li>, each holding one .list__row. A row has a lead (optional), a main block with a title and a soft meta line, and a trail (optional). The row is a <div> when it is only information. A meta line of short facts takes data-facts and one <span> per fact: the dot between two facts is drawn for you, and when the line wraps, no line starts or ends with a dot. A stand-alone list takes data-variant framed (its own 2px frame); inside a card, a panel or an accordion body leave it bare, because the container is the frame.

Rows that go somewhere

When the whole row is a link or a button, it is the target: the full width and at least 56px tall. The chevron is decoration (aria-hidden) and mirrors in right-to-left. A value before the chevron shows the current setting. Hover, focus and press tint the row; the ring is drawn inside it.

Leading slot

An avatar, a bare icon, or a square tile in a tone. The square tile is the owner's card tile: a 44px square with a 2px frame holding one icon. There is no circle behind an icon, because a tinted circle carries nothing.

Trailing slot

The end of a row holds a value, a Tag, a chevron, or one control. A row is either the control (a link, button or label) and its trail is decoration, or it is static and its trail holds one control: never a control inside a control. A toggle in a settings row is a Switch in a static row. What the trail holds goes to one of two slots. Things made of words (a value, a tag, a button with a label) sit beside the title and move under it, aligned with its first letter, when the row is too narrow; they are never split into pieces. Things the size of an icon (a chevron, an icon, the current row's check) keep the end of the row at every size.

Current row

aria-current (or aria-pressed on a button) inverts the row: the text colour becomes the fill. It also adds a check and makes the title bolder, so the current row is three things, none of them a colour. Hover still tints on top.

Inside a card

Inside a .card the list reads the card's own ink, soft ink and fill, so the same markup is right on a plain card, a toned card and the inverted one. In a card panel it runs edge to edge under the bar. On a toned card the current row is the only inverted row, so "which one am I on" has one answer: the dark row with the check.

Reflow

A list has two layouts and every row of it uses the same one, so a list is never ragged. While each title keeps at least 6rem and its longest word beside its value, values sit at the end. When one row cannot, every value moves under its title, aligned with the title's first letter (the iOS large-text pattern), and the lead and the chevron or icon stay where they are. A few lines of script measure this (src/js/46-list.js, with SG.fit); without it a list narrower than 14rem stacks. The lead, the icons and the row's insets are chrome: they stop at their 100% size, so at 200% text the words keep the room. Drag the corner of the dashed box, or raise the text size.

Key / value

A description list for facts about one thing: a photo's adjustments, a deck's numbers, a plan. <dl class="kv"> of <div><dt><dd></div> groups, which HTML allows. The key is a label (uppercase in CSS, natural case in the HTML); the value is what you read, with tabular figures and the true minus sign (U+2212). By default it wraps to as many columns as fit, so it reflows at 320px without scrolling sideways.

Anatomy

  1. List: <ul role="list">, no frame by default; rules between rows are 1px in the text colour. data-variant set to framed adds the 2px frame and the card radius.
  2. Row: at least 56px tall, padded 16px at the sides, edge to edge so the whole width is the target. A grid of four slots: lead, main, value and end. The height floor, the insets and the slots for pictures and icons are chrome: they stay that size at any text size.
  3. Lead (.list__lead): a 44px slot for an avatar, a 24px icon or a square tile (data-shape="tile"). It stays beside the title at every text size.
  4. Main (.list__main): .list__title (600) over .list__meta (soft ink, tabular). With data-facts, a dot sits between two facts on one line, never at the start or end of a line.
  5. Trail (.list__trail): a wrapper only. A .list__value, a tag or a button with a label go to the value slot (they move under the title when the row is narrow); a .list__chevron, a 20px icon or an icon-only button go to the end slot (they never move).
  6. Key / value: dl.kv with dt in label type and dd in body type.

API

List and key / value attributes
AttributeValuesEffect
class="list"data-variant="framed"The list. Framed: a 2px frame and the card radius, for a stand-alone group.
class="list__row"The row inside each <li>. An <a>, <button> or <label> is pressable; a <div> is information.
class="list__lead"data-shape="tile", data-toneThe leading slot. Tile: the owner's square with a 2px frame, in a tone.
class="list__main", __title, __metaThe text block.
data-facts on .list__metaone <span> per factA line of short facts ("Books · 14 April"). The dots are drawn between facts and hidden from assistive tech; a fact stays whole while it fits a line, and a wrapped line never starts or ends with a dot.
class="list__trail", __value, __chevronThe end of the row. Words go to the value slot, icons to the end slot.
aria-current / aria-pressedpage, trueThe current row: inverted, a check (in place of a chevron) and a bolder title.
aria-disabled="true"Faint, blocked. Give a reason in aria-describedby.
class="kv"data-layout="rows", --kv-minThe key / value grid. Rows: ruled pairs. --kv-min: the narrowest a cell gets (default 9rem).

Accessibility

List keyboard and screen reader behaviour
InteractionBehaviour
TabEach pressable row is one tab stop. The ring (3px) is drawn inside the row, in the row's own ink, so it shows on the inverted current row too.
Enter / SpaceA link follows on Enter; a button activates on both.
Screen readerrole="list" keeps the list semantics that list-style: none would drop in Safari. A row's name is its text in order: title, meta, value. dl is read as a description list. Chevrons and leading icons are hidden.
ColourCurrent is inversion, a check and bold. The meta line and keys are 7:1 (soft ink). Rules are the text colour.
TouchA row is at least 56px tall and full width. Rows touch, so there is no gap to size; nothing in a pressable row is a second target.
Zoom / text sizeThe words grow and wrap between words; the lead, the icons and the insets stay their size. When a row has no room, every value of the list moves under its title, aligned with it; chevrons and icons stay at the end. The key / value grid drops to one column.
Reduced motionThe tint fades in and out with no travel.
Forced coloursRules and frames are CanvasText; hover and focus get a 4px Highlight outline inside the row; the current row gets a 4px Highlight bar at its start, and keeps its check and bold title.
