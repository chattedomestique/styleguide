Components

Scrubber

A scrubber sets one number on a scale: exposure, warmth, strength, a point in a recording. It is a native range input with a ruler under the thumb, the value written out beside it, and minus and plus buttons, so nobody has to drag to use it.

When to use

Do

Use it for a value you want to feel for: brightness, volume, where you are in a clip. Always show the number. Name the parameter: Exposure, not Slider.

Don’t

Use it to pick one of a few options (use a segmented control or swatches), to enter an exact amount (use a number field), or ship it without the step buttons where the value matters.

Examples

Dial

The default. Ticks mark the scale, the ones between the origin and the thumb are darker, and the value is written out top right. data-origin says where the fill starts: for exposure it is 0, the middle, so the darker ticks grow left or right from it.

+12

Brighter shadows, flatter highlights.

Plain

For a value that only grows from the start, like strength or progress, and for seek bars: a rail with a fill inside it and the thumb on top. The Player uses this one.

35%

Readouts

data-format decides how the number is written, for the eye and for aria-valuetext. Negative numbers use the true minus (U+2212), never a hyphen. Add data-unit for a suffix. Register your own with SG.scrubber.formatters.name = function (value, input) { return { text, spoken } }.

States

The thumb is a circle you press, so it follows the button: flat at rest, raised with a hard shadow and an accent fill when it can be pressed, sunk while you drag. Step buttons at either end are aria-disabled, not disabled, so focus stays where it is when the last step lands. The is-* classes only force a state for this page (the Focus specimen is out of the tab order, since its ring is always drawn; the others are live sliders).

On a dark stage

Pro editors live on a dark surface so the photo is the brightest thing on screen. Put data-theme="dark" on the tray: it is an island, every role is re-derived, and the ring, ticks and thumb follow it with no extra code.

Anatomy

  1. Label (.scrubber__label): a real <label for>. It is the accessible name, so the parameter is named for everyone.
  2. Readout (.scrubber__value): an <output> with tabular figures, so the number does not jitter while you drag. aria-live="off": the slider itself announces its value, and a live output would say everything twice.
  3. Step buttons (data-step="down|up"): 36px circles with a 44px hit area. The pointer alternative to dragging (WCAG 2.5.7), and a fine adjustment for anyone.
  4. Ruler (.scrubber__ticks): decorative, aria-hidden, built by the script. Every Nth tick is taller (data-major), and so is the origin. On a bar too narrow for them (under 4px apart) the minor ticks go and the tall ones stay.
  5. Input (.scrubber__input): the native range, 44px tall, transparent. The whole bar is the target and clicking it jumps the thumb.
  6. Thumb: a 28px circle with a 2px frame. The only thing that lifts.
  7. Hint and Reset (.scrubber__foot, optional): a sentence (<p>) about what the value does, and a button (data-reset) that returns to the input’s default value, aria-disabled while there is nothing to undo. They share a line while they fit; then Reset goes under the sentence, at the start.

API

Scrubber attributes
AttributeValuesEffect
class="scrubber"The wrapper. Holds the custom properties the script sets (--_from, --_to).
data-variantplain (default: dial)Rail and fill instead of a ruler.
data-formatnumber, signed, percent, timeHow the readout and aria-valuetext are written.
data-unitany textAppended to the readout and the spoken value: data-unit=" EV".
data-origina value between min and maxWhere the fill and the darker ticks start. Default: the minimum.
data-ticks / data-majornumbersDial only. Divisions (default one per step, or 20) and which Nth tick is tall (default 5).
--scrubber-thumba lengthThe drawn thumb, default 1.75rem. The hit area stays 44px.
data-stepdown, upOn a button: one step down or up. Fires input and change, announces the new value.
data-resetOn a button: back to the input’s data-default, or its value attribute if there is none.
data-fitbeside, under (set by the script)On the parent of one or more scrubbers: every readout beside its label, or every one under it. Measured, so a panel decides as one.
SG.scrubber.sync(el)Call after you set a value, min or max from code (that fires no event).

Accessibility

Scrubber keyboard and screen reader behaviour
InteractionBehaviour
TabOne stop on the slider, one on each step button. The ring sits around the whole bar and the thumb lifts.
Left Right (Down Up)One step down or up. Native.
PageDown PageUpA larger step (about a tenth of the range). Native.
Home EndThe minimum and the maximum. Native.
Click or tap the barThe thumb jumps there. Dragging is never the only way (WCAG 2.5.7).
Step buttonsEnter / Space step by one and announce "Exposure +13". At the ends they are aria-disabled, so focus stays put.
Screen reader"Exposure, slider, +12" from the label and aria-valuetext. The numbers carry the state; the ruler is hidden.
TouchThe bar is 44px tall and the buttons have 44px hit areas. The input takes horizontal drags; vertical scrolling passes through.
Zoom / text sizeThe label and the readout grow with the text; the bar, the thumb, the ticks and the buttons keep their 100% size, so minus, bar and plus stay on one line on a phone at 200% text. When the label and the readout cannot share a line, the readout goes under the label and starts where it starts; scrubbers that share a parent (a tool’s panel) do this together, measured, so one panel never mixes the two.
Reduced motionThe thumb does not travel when it lifts; the fill change stays.
Forced coloursTicks, fill and thumb take system colours; the thumb’s frame goes 4px Highlight on hover and focus.
