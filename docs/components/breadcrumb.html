Components

Breadcrumb

A breadcrumb shows where a page sits in a hierarchy and gives a way up to every level above it. It answers "where am I?" and "how do I go back up?", which the back button cannot.

When to use

Do

Use it when content is nested three or more levels deep and people arrive from search or a link: Library / Decks / Shapes. Put it above the page title. Name each level the way the page itself is named.

Don't

Use it for the app's main navigation (the dock), for steps in a process, or where the structure is flat: a two-level app only needs Back in its app bar. Don't show the trail of pages the reader happened to visit: it is the path through the structure, not their history.

Examples

Basic

Every level above the page is a link, underlined. The page itself is bold and not underlined, so the two are told apart by more than colour, and it carries aria-current="page". The chevrons are drawn by CSS and are not in the markup.

A long trail

When the trail is deeper than fits, keep the first level, the last two, and fold the middle into one … button. It is drawn at the scale of the words around it (its target is still 44px), and it is a disclosure (aria-expanded, aria-controls naming the hidden items): one press shows every level in place, and the button keeps its name, Earlier levels, so nothing is announced twice. While open it keeps a light tint.

It wraps, it never truncates

A trail in a narrow column drops onto a second line. Nothing is cut off with an ellipsis, because a clipped name is not a link anyone can use. The box starts at 14rem on every screen, so it wraps on all of them; drag its corner wider to watch the trail close up.

Anatomy

  1. Landmark (<nav class="breadcrumb" aria-label="Breadcrumb">): a labelled navigation region. The label distinguishes it from the main navigation.
  2. List (<ol class="breadcrumb__list" role="list">): ordered, because the order is the meaning.
  3. Ancestor: a link, underlined, 44px tall with a hit area 44px wide even for a short word.
  4. Separator: a chevron in front of every item after the first, drawn by CSS, flipped in right-to-left layouts, invisible to assistive technology.
  5. Current page: the last item, bold, not underlined, with aria-current="page". It may be plain text or a link to itself.
  6. Earlier levels (optional, breadcrumb__more): a small circle with an ellipsis, at the scale of the words, in place of the middle of a long trail. A disclosure button with a 44px target.

API

Breadcrumb classes and attributes
NameValuesEffect
class="breadcrumb"on a <nav aria-label>The landmark; sets the type (14px).
breadcrumb__listan <ol role="list">The wrapping row of items and separators.
aria-current="page"on the last itemBold, no underline. Exactly one.
breadcrumb__morea <button> holding an ic--ellipsis, with an aria-labelThe collapsed middle: a small circle drawn at text scale, a 44px target.
data-sg-discloseon a button with aria-expanded and aria-controlsShows or hides the listed items (43-disclose.js).
sg:disclose{ button, open }Fired after the disclosure flips.

Accessibility

The APG Breadcrumb pattern.

Breadcrumb keyboard and screen reader behaviour
InteractionBehaviour
Tab / Shift+TabEach link is a tab stop, in trail order. It is ordinary navigation: no arrow-key model.
EnterFollows a link. Enter or Space on the "Earlier levels" button shows the hidden levels; focus stays on the button.
Screen reader"Breadcrumb, navigation; list, 3 items; Library, link; Decks, link; Shapes, current page, link". The separators are never read.
Touch44px tall links, each with a 44px-wide hit area and more than 8px between them.
Zoom / text sizeThe trail wraps between items, never inside a word. At 200% text and at 320px nothing is clipped or truncated; the 44px targets do not grow with the text, so a wrapped trail keeps its lines close.
Reduced motionNothing moves. On hover and press the underline steps away from the word.
Forced coloursLinks use the system link colour; the chevrons use CanvasText; the current page keeps a rule under it as well as its weight.
  • Give the <nav> a label that is not "navigation", so it is told apart from the main one. If a page has more than one breadcrumb, label each uniquely.
  • The last item is the current page; do not link the trail's final item to a different page.
  • Keep the trail the same on every page that shares a level (WCAG 3.2.3).

Icons. The ellipsis of the “Earlier levels” button comes from dist/icons.css; the main bundle ships only plus, minus, close, check and arrow. Link icons.css in your app, or define the masks yourself: an .ic with no mask paints a solid square.

Tokens used

--type-meta, --bw, --bw-heavy, --radius-pill, --chrome-hit, --space-1, and whatever colour the surroundings set (currentColor), the "…" included.
