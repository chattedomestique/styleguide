Components

Sparkline

A sparkline is a trend in a corner of a number: which way is it going? It draws one line with no axes, so it never says how much. The numbers sit next to it as text, and it carries a sentence that says the trend in words.

When to use

Do

Put it beside the current value, inside a stat card or a table row, and write its label as a sentence with the direction, the span and the endpoints. Say "up" or "down" in words and an icon too: the line's angle is not a cue for everyone.

Don't

Use it to read values (no axis, no scale), colour the line green or red to say good or bad, or draw it with no text alternative. For a few values the reader must compare, use a bar chart.

Examples

In a stat card

The recipe: an eyebrow, the figure, the sparkline, and one line of meta that says the direction with an icon and words. The line takes the card's ink, so it works on a toned card; the end dot has a ring in the card's own fill. The second card is toned, to show it follows.

Sizes

data-size sets the height (1.75, 2.5 or 4rem); the width is whatever the layout gives it, and the line stays 2px. Set min and max yourself when several sparklines must share a scale, like the flat line below (0 to 20 cards).

In a table

A fixed-width sparkline in a cell turns a column of numbers into a column of numbers and trends. The row's name and its current value stay text; the trend column's header says what it is.

From data

SG.chart.sparkline(values, { label, area, dot, min, max }) returns the <svg> string. The label is required; a sparkline without a sentence is refused. SG.chart.points(values) gives just the coordinates if you template it yourself. This page runs the code below, and the sparkline under it is what it returns.

const label = [
  'Index fund, last 5 days:',
  'up 1.7%, from $278.90',
  'to $283.72',
].join(' ')
const values = [278.9, 279.4,
  277.1, 280.3, 283.72]
el.innerHTML = SG.chart
  .sparkline(values, {
    label,
    area: true,
  })

Writing the text alternative

Name the subject, the span, the direction, and the two endpoints. One sentence; no "chart of". A reader who cannot see the line should lose nothing the line told a sighted reader.

Anatomy

  1. Box (.spark): an SVG that fills the width and has a rem height. role="img" and a label are required.
  2. Line (.spark__line): a polyline in the text colour, 2px (the frame weight) however the box stretches.
  3. Area (.spark__area, optional): a flat wash, the text colour mixed 14% into the surface. No gradient.
  4. End dot (.spark__dot on a ring .spark__dot--ring): where the line ends now, 12px. It is a zero-length path with a round cap, so it stays a circle in a stretched box.

Accessibility

Sparkline keyboard and screen reader behaviour
InteractionBehaviour
TabNothing to reach. A sparkline is not a control and shows nothing on hover.
Screen readerOne image, named by the sentence: "Index fund, last 12 days: up 1.7%, from $278.90 to $283.72". The figure and the direction line beside it are ordinary text.
ColourThe line is the text colour: 7:1 on its surface (and 3:1 is all a graphic needs, WCAG 1.4.11). Direction is carried by words and an icon next to it, never by a green or red line (1.4.1).
Zoom / text sizeThe box is rem-high and fills the width, so it never overflows; the line stays 2px.
Reduced motionNothing moves. It does not draw itself in.
Forced coloursLine and dot become CanvasText, the ring and wash become Canvas.

Tokens used

currentColor (the card's ink), --paper, --card-bg when inside a card, --bw, --space-3.
