Components

Bar chart

Bars compare a handful of values by length. They are plain HTML and CSS (every bar is a box sized by one number), so the numbers stay text, the chart grows with the reader's text size, and the data is always one disclosure away as a real table.

When to use

Do

Compare up to about eight things: days, weeks, categories. Print the value on the bar, say what the chart says in its label, and let one bar carry the emphasis.

Don't

Tell series apart by colour alone, use more than six series, or draw one bar (that is a number: use a Card figure). For parts of a whole use the donut; for a trend in a corner, a sparkline.

Examples

Weekly, with a selected bar

An interactive chart is a radio group: each column is a real input type="radio" inside its label, so the arrow keys, the state and the group all come from the browser. The selected bar is filled with the accent, its frame doubles, its value goes heavy and its day is inverted: four cues, none of them only colour. The readout is a live region that repeats the full sentence. The dashed line is the weekly average, and the note under the chart says so.

A picture with a summary

When nothing on the chart can be chosen, it is one image: role="img" with a label that says what the chart says (the headline, not "bar chart"), and the table for anyone who wants the rest. aria-current marks today. Nothing lifts or casts a shadow here, because nothing can be pressed.

Stacked, tone plus pattern

Parts of each bar are told apart by tone and pattern (food is hatched, transport dotted, shopping cross-hatched), and the legend carries the same keys with the names. Segments share a frame line. In the wire palette, where tones are six close greys, or in forced-colours mode, the patterns are what still works.

Horizontal, ranked

Long names and many rows read better sideways. Put the largest first. Use data-orientation="horizontal"; a vertical chart also flips to this layout on its own when it is narrower than 15rem (try the box below).

Narrow and large text

Drag the corner of the dashed box. Below 15rem the weekly chart turns itself into the horizontal one, because seven columns of three-letter labels need about 2.1rem each. The threshold is in rem, so 200% text flips it twice as early, and labels never overlap or clip.

Values on selection only

data-values="selected" prints only the chosen bar's number. The value row is still reserved, so nothing jumps. Use it when printing every number would crowd the bars.

States

A bar in an interactive chart is chosen, like a chip or a tab, so it follows the selection-control recipe: the solid fill belongs to the chosen bar alone. Hover and keyboard focus raise the outline bar (2px, with its hard shadow) without filling it; pressing puts it back on the baseline with a light tint, at once; chosen is filled, framed twice, its value heavy and its day inverted, and it still lifts under the pointer. Focus adds the ring round the bar and its value, so the day under it stays clear. The is-* classes only force a state for this page.

Anatomy

  1. Title (.bars__title): the figcaption. Names the chart and labels the radio group.
  2. Readout (.bars__readout): an <output> that repeats the selected bar as a sentence. Its height is reserved.
  3. Plot (.bars__plot): a grid of two rows, track and label. Each column is a subgrid, so tracks are one height and labels line up.
  4. Track (.bars__track): holds the value and the bar, and draws the 2px baseline. The bar grows out of the baseline: one line, not two. On its side, the tracks draw one axis down the whole plot; stacked under their labels (200% text in a narrow card), each bar closes its own edge instead.
  5. Bar (.bars__bar, or .bars__stack of .bars__seg): a tone, a pattern and a 2px frame. Its size is --v.
  6. Value (.bars__value): at the bar's cap, tabular figures, rounded for the eye. The exact number is in the readout and the table.
  7. Axis label (.bars__label): uppercase structure. Inverted on the selected bar.
  8. Reference line (data-ref, --ref) and its note (.bars__note): a dashed line is only allowed if something says what it is. It is one line in every layout; the note's dashed key stays beside the first line of its words.
  9. Data (.bars__data): a <details> holding a Table of the same numbers.

Drawing the data: SG.chart.scale([18.5, 42, 27.3]) returns the --v values (0 to 1, against the largest by default).

Accessibility

Bar chart keyboard and screen reader behaviour
InteractionBehaviour
TabOne stop in the radio group (the selected bar), then the "Show the data as a table" summary. The ring is inset on the bar's track (the bar and its value), so a neighbour never covers it and it never runs through the day's name.
Arrow keysMove to the next or previous day and select it (native radio behaviour); the readout updates.
Enter / SpaceOn the summary: opens the table. Space on a radio selects it.
Screen readerInteractive: "Spending by day, radio group", then "Thursday: $62.40, the highest day, radio button, 4 of 7, checked". Static: one image whose label is the headline ("Spending by day ... Highest Thursday at $62.40 ..."). Either way the table carries every number.
ColourNever the only cue (WCAG 1.4.1). Series differ by pattern and by the legend; selection is fill, doubled frame, heavy value and inverted label. The 2px frame carries the 3:1 boundary the pale tone cannot (1.4.11).
TouchA whole column is the target (about 47px wide at 390px, the full plot height). Selecting is a tap: no drag, no hover-only tooltip. The value is printed, not revealed on hover.
Zoom / text sizeAll sizes are rem. The layout flips to horizontal when seven labels would not fit, so nothing collides at 320px or 200% text. A day's label that fills its column takes Archivo's extra-condensed width (SG.chart measures the labels), so it stays whole and never touches the chosen day's plate. Stacked under their labels, the bars keep one unbroken average line behind the labels, and the data summary wraps into two even lines.
Reduced motionThe only motion is the bar lifting on hover or focus; the travel is multiplied by --move, so it becomes the hard shadow appearing in place, and the press tint is a plain colour change. Nothing draws itself in.
Forced coloursFills and shadows vanish; frames become CanvasText, patterns stay (they are drawn with a system colour), the selected bar gets a 4px frame and the selected label a 4px box, focus a 4px Highlight.
