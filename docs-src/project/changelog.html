Unreleased

Added on top of 0.2.0 and not yet given a version number. Giving it one is the owner's call: bump package.json, then move this list under the new number. The steps are on Upgrade.

  • A visual pass at phone size. Every element's demos were reviewed at 390px with 100% and with 200% text, and the elements were reworked against what the review found. The system gained rules for it:
    • Chrome caps. Words, and an icon inside a line of words, grow with the reader's text size; the insets of controls and containers, icon-only controls and their 44px targets, the slots that hold them and the frames of pictures stop at their 100% size (--chrome-*, on Space).
    • Selection states. A selection control keeps the solid fill for selected, on or current: hover and focus only raise it, a press tints it. Actions keep the owner's states (Interaction).
    • One-row bars. A bar or a row of controls never wraps raggedly: it stays one row or switches its whole layout, measured by SG.fit where CSS cannot know (Layout).
    • Words break only when they must. overflow-wrap: break-word everywhere; the lint fails anywhere (rule wrap), which had shattered words in flex rows. Running text uses text-wrap: pretty, and numbers never break.
    • Pills keep their ends. A button's radius is half its nominal height, so a label that wraps keeps the pill's shape.
    The Status page now separates the automated checks from the screenshot review, which a person keeps in docs-src/project/visual-review.json; tests/design.mjs reports the signs of a broken-looking layout for that review (Testing). The reasons and how to undo each are on Decisions.
  • Fifty elements, each with a docs page and an interaction spec in tests/components/. Status says how far each one has got:
    • Forms: Field, Input, Select, Choice, Switch, Slider, Stepper, Keypad.
    • Selection and navigation: Tabs, Chip, Segmented control, App bar, Dock, Breadcrumb, Pagination.
    • Surfaces: Tag, Avatar, Divider, Accordion, Tile, List, Stat (a recipe on Card, no CSS of its own).
    • Overlays: Dialog, Sheet, Menu, Popover, Tooltip.
    • Feedback: Alert, Toast, Progress, Spinner, Skeleton, Empty state, Marquee.
    • Data: Table, Bar chart, Sparkline, Donut chart, Legend, Calendar, Agenda.
    • Media and tools: Media, Carousel, Filmstrip, Gallery, Toolbar, Scrubber, Swatch, Timeline, Player.
  • Foundations pages: Colour, Tones, Typography, Space, Shape, Interaction, Motion, Icons, Layout.
  • Start and Accessibility pages: Install, Customize, Upgrade, PWA, Checklist, Testing, Manual and Patterns.
  • Project pages: Status, Decisions, References, Contributing, this changelog, and the Audit, which the build generates from AUDIT.md so the two cannot disagree.
  • The build. Besides the everything bundle (styleguide.css, styleguide.js) it now writes core.css (tokens, base, layout, utilities), one file per element in dist/elements/, one file per script in dist/js/, minified scripts, and dist/elements/manifest.json, which says what each element builds on and which scripts it has. dist/ and docs/ are committed, and npm run build:check fails when they are stale.
  • CI. .github/workflows/ci.yml runs the gate on every push to main and every pull request; see Decisions.
  • The gate. A lint rule can be waived on one line with a written reason, /* lint-allow rule: why */ (or for a whole file, lint-allow-file); every run lists the waivers it honoured, so an exception is allowed but never invisible. A private --_x property shared by a family of files (Input and Select) is a warning instead of an error. opacity is flagged only when it dims. Uppercase is judged by where it sits. Comments in scripts are ignored. overflow is no longer flagged by the lint: the accessibility gate measures what it can break, which is the focus ring's contrast and text cut off by a clipping frame.
  • Foundation fixes. A palette block now starts from the default knobs, so an island that names a palette looks exactly like a page with that palette instead of inheriting the page's (a "sand" island in a mint page kept mint's accent); npm run test:contrast compares every island with a page of the same palette. Higher contrast reaches islands too: a palette inside a higher-contrast page keeps its 7:1 text, and data-contrast="more" works on any element, not only the page. SG.prefs keeps the look an app writes on <html>: choosing the guide's own default (square, default) over it is stored explicitly, reset() puts the app's attributes back, and <html data-sg-prefs-key="myapp:prefs"> keeps two apps on one origin apart.
  • Docs. Plain tables stack into labelled rows on a phone (the build does it, with ARIA roles); tables that must scroll say so and are focusable only when they do. Page titles are sized from their column and no longer break inside a word. The overview has a start path and a generated index of every page. The Status page is generated from the gates: npm run status.
  • Large text. A design review of every page found words broken letter by letter, wrapped controls turning into ovals, and cut-off times at 200% text. They are fixed in the elements (Button, Choice, Segmented, Dock, Tag, Toast, Agenda, Calendar, Scrubber, Marquee and others) and pinned by specs; forced .is-focus specimens now draw the same ring as real focus.
  • The accessibility gate now proves a range input's ring by comparing pixels, understands transparent forced-colours outlines, opens exclusive <details> groups, and lets a demo that cuts text on purpose say so with data-allow-clip. SG_JS=min npm run test:components runs the specs against the minified bundle.

0.2.0 · 2026-09-30

Re-founded on the Flashcards style sheet v0.1.

  • The colour engine: dark, higher contrast, six palettes, status tones, bold emphasis. Every pair is checked in a real browser by npm run test:contrast.
  • Motion is on (gate 4 is open for the guide; see Decisions).
  • Button, the reference element every other one copies.
  • The accessibility gate (npm run test:a11y) and the extended checker (npm run lint).
  • Card: study renamed portrait (the old name is kept as an alias); hover rules gated for touch; long words no longer clip at large text.
  • What the audit of the original sheet found, and what was done about each finding, is on the Audit page.
