Unreleased

Added on top of 0.2.0 and not yet given a version number. Giving it one is the owner's call: bump package.json, then move this list under the new number. The steps are on Upgrade.

  • Fifty elements, each with a docs page and an interaction spec in tests/components/. Status says how far each one has got:
    • Forms: Field, Input, Select, Choice, Switch, Slider, Stepper, Keypad.
    • Selection and navigation: Tabs, Chip, Segmented control, App bar, Dock, Breadcrumb, Pagination.
    • Surfaces: Tag, Avatar, Divider, Accordion, Tile, List, Stat (a recipe on Card, no CSS of its own).
    • Overlays: Dialog, Sheet, Menu, Popover, Tooltip.
    • Feedback: Alert, Toast, Progress, Spinner, Skeleton, Empty state, Marquee.
    • Data: Table, Bar chart, Sparkline, Donut chart, Legend, Calendar, Agenda.
    • Media and tools: Media, Carousel, Filmstrip, Gallery, Toolbar, Scrubber, Swatch, Timeline, Player.
  • Foundations pages: Colour, Tones, Typography, Space, Shape, Interaction, Motion, Icons, Layout.
  • Start and Accessibility pages: Install, Customize, Upgrade, PWA, Checklist, Testing, Manual and Patterns.
  • Project pages: Status, Decisions, References, Contributing, this changelog, and the Audit, which the build generates from AUDIT.md so the two cannot disagree.
  • The build. Besides the everything bundle (styleguide.css, styleguide.js) it now writes core.css (tokens, base, layout, utilities), one file per element in dist/elements/, one file per script in dist/js/, minified scripts, and dist/elements/manifest.json, which says what each element builds on and which scripts it has. dist/ and docs/ are committed, and npm run build:check fails when they are stale.
  • CI. .github/workflows/ci.yml runs the gate on every push to main and every pull request; see Decisions.
  • The gate. A lint rule can be waived on one line with a written reason, /* lint-allow rule: why */ (or for a whole file, lint-allow-file); every run lists the waivers it honoured, so an exception is allowed but never invisible. A private --_x property shared by a family of files (Input and Select) is a warning instead of an error. opacity is flagged only when it dims. Uppercase is judged by where it sits. Comments in scripts are ignored. overflow is no longer flagged by the lint: the accessibility gate measures what it can break, which is the focus ring's contrast and text cut off by a clipping frame.

0.2.0 · 2026-09-30

Re-founded on the Flashcards style sheet v0.1.

  • The colour engine: dark, higher contrast, six palettes, status tones, bold emphasis. Every pair is checked in a real browser by npm run test:contrast.
  • Motion is on (gate 4 is open for the guide; see Decisions).
  • Button, the reference element every other one copies.
  • The accessibility gate (npm run test:a11y) and the extended checker (npm run lint).
  • Card: study renamed portrait (the old name is kept as an alias); hover rules gated for touch; long words no longer clip at large text.
  • What the audit of the original sheet found, and what was done about each finding, is on the Audit page.
