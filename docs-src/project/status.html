Status

Every element moves through six gates, in order. This page records where each one stands. Card and Button are the two that have been through every gate and are waiting for sign-off; the rest were built since, and none has been signed off.

The gates

The full list, with the question each gate asks, is on Contributing: 0 brief, 1 wireframe, 2 states, 3 colour, 4 motion, 5 freeze. Gate 5 is the owner's: an element is frozen when its docs are complete, its accessibility gate is green, its screenshots have been looked at, and the owner has said so.

Everything built since

Last run: 2026-09-30, on the merged tree of every slice. Gates 0 to 4 are marked closed for an element when three things hold at once: its spec in tests/components/ passes, npm run lint reports no error in its files, and its page passes npm run test:a11y in all five appearances. Otherwise the cell says open and the findings are in the last column. That is the mechanical part. The squint test in data-palette="wire", and whether it looks right in the screenshots, are looks by a person, and this table does not record them. How this table is kept

  • It is kept by hand, in two places: this page and STYLE.md section 6. When an element moves, edit both in the same pull request, and add a line to the Changelog.
  • To refresh the evidence, run the three commands: npm run lint, npm run test:components and npm run test:a11y. A cell is only ever closed because a check passed.
  • A generated table, so that nobody types a status, is still open; see Decisions.
  • Everything here was measured in Chromium. Nothing has been verified in Safari, Firefox or with a screen reader; see Decisions.
