Legend

A legend says which series is which. Its swatch is the series' tone and its pattern, and its name is words, so a chart never asks anyone to match colours by eye.

When to use

Do

Give every chart with two or more series a legend, even when you also label marks directly. Put the number in the legend when the chart does not print it.

Don't

Use a legend for a single series (the chart's title already says what it is), or colour the legend's text to match the series. Text stays ink; the swatch carries identity.

The six series keys

A series is a tone slot, and the tone brings its pattern with it (set in 00-chart-marks.css, so nobody has to remember). Tone 1 is solid and is the one to use for a single series. In the wire palette the six fills are six close greys; try it with the appearance panel and the patterns are still six different things. Tones carry rhythm, never meaning: a series means what its label says.

Any mark can be a key

The same swatch is available as .mark anywhere a chart-less thing needs to say "this colour and this pattern": a tag in a table cell, a category chip. It is a 2px-framed box with the tone fill and its pattern; size it yourself.

Anatomy

  1. Key (.legend__key): a 20px swatch, tone fill + 2px frame + pattern. Decorative, so aria-hidden.
  2. Label (.legend__label): the series name, in ink. Wraps; never truncated.
  3. Value (.legend__value): optional, semibold, tabular, right-aligned.
  4. Share (.legend__share): optional, soft ink, tabular.

Accessibility

Legend keyboard and screen reader behaviour
InteractionBehaviour
TabNothing to reach: a legend is a list, not a set of controls.
Screen reader"List, 5 items", then "Food, $284, 22%". The keys are hidden because the label already names the series.
ColourThe swatch is tone + pattern, so series are told apart without colour (WCAG 1.4.1). The 2px frame gives the swatch its 3:1 edge (1.4.11). Text is ink, never the series colour.
Zoom / text sizeLabels wrap; the key stays 20px (rem), and values stay aligned because the list is one grid.
Forced coloursThe frame becomes CanvasText and the pattern is drawn with CanvasText, so the six keys still differ.
