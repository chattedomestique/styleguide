Marquee

A ticker strip: a line of short announcements that drifts past. It is for "nice to know" (what's new, sync status, a headline), and it is built so nobody is ever trapped by it: a Pause button that is always there, a static wrapped list when paused or when motion is reduced, and a single reading for screen readers.

When to use

Do

Use it for information that is also available elsewhere: a headline that links to the article, a sync status that also lives in settings. Keep each item to a few words.

Don't

Put anything essential in a ticker: a price, a deadline, an error. Don't make people chase a link that is moving, and don't leave out the Pause button "because it is small".

WCAG 2.2.2 Pause, Stop, Hide

Anything that moves on its own for more than five seconds, beside other content, needs a way to pause it. Pausing on hover or focus does not count, because it stops only while the pointer is there. So the button is required, and the script refuses to start the loop without it.

Examples

Default strip

A paper strip with a 2px frame: a label, the toggle, and the scrolling list. Press the button (or Space on it) to pause: the movement stops and the text wraps, fully readable. Hover or focus anywhere in the strip also freezes it as a courtesy. The markup shown is what you write; the script adds the loop on top.

When it moves and when it does not

Marquee motion rules
SituationResult
DefaultScrolls at data-speed px per second (40 by default), so long and short lists move at the same pace.
Pause pressed (aria-pressed="true")Animation off, loop copy hidden. The strip becomes a title row (label and toggle) over the text, which wraps. Press again to resume.
Pointer over the strip, or focus anywhere inside itFrozen in place (animation-play-state: paused). A courtesy, not the pause mechanism.
Reduced motion (OS, or the Motion switch in Appearance)Never starts. Static wrapped list, and no Pause button: there is nothing to pause. Try it: switch Motion to Reduced.
The text fits in the stripNothing to scroll, so nothing moves, and the button is hidden.
Too little room for a moving line (200% text on a phone)Static wrapped list, every item whole, and the button is hidden. It comes back when there is room again.
No script, or no toggle in the markupStatic wrapped list. The loop needs JavaScript (a continuous loop needs a duplicate) and needs the button.
Right-to-leftDirection mirrors with :dir(rtl).

Anatomy

  1. Strip (.marquee): a rectangle with the 2px frame (--radius-card) in a tone or on paper. It is not pressable, so it casts no shadow.
  2. Label: the caption at the start, in the uppercase label style on the tone's fill. Not interactive.
  3. Toggle: the small round button, 36px drawn with a 44×44px hit area, stable name "Pause ticker", aria-pressed for state (filled and a doubled frame when paused), an icon that swaps between pause and play. It comes before the moving text in the DOM, so a keyboard or screen-reader user meets the control that stops the motion before the motion; order puts it at the end visually. It is hidden whenever nothing can move.
  4. Viewport: clips the moving track, with block padding so a link's focus ring is never clipped. There is no edge fade: a fade is a gradient.
  5. List: a real <ul>, read once, left in the DOM for assistive technology. Items are separated by a small square drawn with a box, not a text glyph, so it is not read aloud. A single item that is not moving has no square: it would separate nothing.
  6. Loop copy (added by script): a second list, aria-hidden and inert, for the continuous wrap.

Accessibility

Marquee keyboard and screen reader behaviour
InteractionBehaviour
Screen readerThe group is named ("Announcements"), the list is read once, item by item. The loop copy is aria-hidden and inert. Nothing is live: a moving ticker is never announced, so updates that matter must also appear somewhere that is (a status region, a toast).
TabReaches the toggle (and any links in the list). Entering the strip freezes it.
Space / Enter on the togglePauses or resumes. Announced as "Pause ticker, toggle button, pressed / not pressed".
TouchThe toggle has a 44×44px hit area.
Reduced motionNever scrolls; travel is multiplied by --move (0) and the script also stops the loop so the text wraps instead of sitting clipped.
LegibilityLine height 1.4 and block padding: the reference design clipped the bottoms of capitals ("E" read as "F").
Zoom / text sizeThe words grow with the reader's text size; the strip's insets, the label's box and the toggle stop at their 100% size. Where a moving line would leave a few words of room (200% text on a phone) the strip is a static list, every item whole, and the toggle is hidden.
Focus ringOn the ink band the ring is paper and its halo ink, so it follows the surface.
Forced coloursStrip and label keep real borders in CanvasText; the toggle is a Button, whose border doubles when pressed.
