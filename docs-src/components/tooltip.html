Tooltip

A tooltip is a few words that appear next to a control on hover or keyboard focus, to say what it does or why it is unavailable. It is the native popover attribute, so it sits above even a dialog with no z-index. It never carries the control's name and never carries anything a person on a touch screen needs.

When to use

Do

Use a tooltip to add a shortcut, a consequence or a reason to a control that already has its own name. Keep it to one short line. Wire it with aria-describedby.

Don't

Make it the only name of an icon-only control (that is aria-label), put a link, button or long text in it (that is a popover), or hide anything essential in it: touch screens never show one.

WCAG 1.4.13, all three parts

Dismissible: Esc hides it without moving the pointer or focus. Hoverable: the pointer can travel onto the tooltip and read it. Persistent: it stays until the pointer and focus have left, you press Esc or you press the control.

The button is named by aria-label. The tooltip is its description (aria-describedby) and adds what the name cannot: the shortcut. Hover a button for half a second, or Tab to it (keyboard focus shows it at once). Once one tooltip has been shown, the next shows without the wait.

Hoverable and dismissible

Move onto the tooltip and it stays, so its text can be read and selected at high zoom. Press Esc and it goes without the pointer moving; it stays away until you leave and come back. Inside a dialog, the first Esc only hides the tooltip.

Anatomy

  1. Trigger: any control with its own accessible name and aria-describedby pointing at the tooltip. It may also be aria-disabled.
  2. Tooltip: <div class="tooltip" role="tooltip" popover="manual">, placed right after its trigger. An ink box with paper text, framed in paper, --radius-ctl, 20rem at most. No shadow and no arrow.
  3. Key cap: a <kbd> inside is inverted so it stays readable.

  • A tooltip is never the only accessible name: an icon-only control always has aria-label (or visible text).
  • Text in a tooltip is a description, not content. If people must be able to find it again, it belongs on the page.
