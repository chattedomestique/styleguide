Divider

A line that separates, and can say what comes next. It is flat and static: it never lifts, never has a shadow, and takes the colour of the text around it, so the same divider is ink on a card and paper on an inverted one.

When to use

Do

Use space first and a divider when space is not enough to show that two groups are different: a choice between two ways in, a day in a history, two kinds of action in a toolbar.

Don't

Rule between every line, or use a divider inside a List (its rows already have rules) or a card foot (it has one). Do not count on the quiet divider to mark a boundary: it is decoration.

Rules

A bare <hr> with the class. One line weight per job, as everywhere in this guide: 1px divides, 2px is a frame weight and marks a bigger break. data-quiet uses the faint line colour, for decoration that must stay out of the way.

Thin: the default. Between two kinds of thing in one card.

Frame weight: a section break.

Quiet: decoration only.

End of the examples.

On an inverted card the line is paper, because it is currentColor:

Today

Twelve cards to review

Next session is at 18:00.

Labelled

Text between two rules. The lines are drawn by ::before and ::after, so the label is ordinary text: a screen reader says it, which it would not do for a label inside a role="separator" (whose children are presentational). The label is uppercase structure (--type-label), written in natural case.

or

A divider that names a group

If the label names the group below it (a day, a month, a category), make the element a heading at the right level. It is then in the page outline, and a screen-reader user can jump between the groups. data-align puts the label at the start or end and draws only the far rule.

Vertical

Between siblings in a row. It stretches to the row's height (so the row needs to be flex or grid) with a 24px minimum. A bare <hr> keeps its separator role; add aria-orientation="vertical" only when it really separates controls in a toolbar.

Anatomy

  1. Rule: border-block-start of --bw-thin (or --bw for data-weight="frame") in currentColor. A border, not a background, so forced-colours mode still draws it.
  2. Label (optional): --type-label, uppercase, positive tracking, wraps at large text.
  3. Side rules (labelled): ::before and ::after, each growing to fill. Aligned to a side, the near one is not drawn.
