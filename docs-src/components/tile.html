Tile

The square quick action: Send, Bills, Top up, Study. An icon and a name on a field of colour. You press it, so it has a 2px frame and a hard shadow that appears when it can be pressed; the field is the tone, so a row of tiles gives a screen its colour.

When to use

Do

Use three to eight of them for what people do most, each with a word under the icon. Put the most used first.

Don't

Show a tile with only an icon, use tone to say which one matters, or build your main navigation from them. That is a dock.

Quick actions

A tile is a link or a button, so it is an <a> or a <button>. Put them in a grid with a minimum width; the grid decides how many fit. The icon is a mask in the text colour, directly on the field: no circle behind it.

Tones

The six slots, the inverted ink tone and the four status tones all work. Hover fills with the tone's own solid (--tone-fill); with no tone it fills with the accent. data-emphasis="bold" gives a saturated field.

Badge

A count in the corner, for what is waiting: bills due, unread, new. It is a paper pill with an ink frame, so it reads on any field, filled or not. Put the unit in visually hidden text so the tile's name is Bills, 3 due. A dot with no number is colour alone and is not offered.

As a toggle

A tile that picks something is a button with aria-pressed. On is filled and the frame doubles, so it never depends on the fill being dark.

States

The same two numbers as the button: --lift (0 flat, 1 raised) and --fill (0 outline, 1 filled). Hover and keyboard focus are the same state, so a keyboard user sees what a mouse user sees. The is-* classes below only force a state for this page.

Caption tiles

A field (colour, an icon or a photo) closed by a bar that carries the name. Text never sits on the photo, so its contrast does not depend on what the photo is. On hover the bar swaps polarity where the quick tile fills.

Anatomy

  1. Frame: 2px --line, --radius-tile, a real border so forced-colours mode draws it.
  2. Field: --tone-bg, or --paper with no tone. --fill mixes it toward --tone-fill (or --accent).
  3. Icon: a 24px mask at the start, in the text colour, decorative (aria-hidden).
  4. Label: --type-ctl at 14px, at the bottom. Wraps; never truncated.
  5. Badge (optional): paper pill with an ink frame, top end.
  6. Hard shadow: 4px, zero blur, appears with --lift. It means "you can press this".
