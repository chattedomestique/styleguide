Button

A button does something on this screen: save, add, send, confirm. If it goes somewhere else, it is a link. Buttons are pills and circles because, in this system, circles and pills act and rectangles hold.

When to use

Do

One primary button per screen or card. Name it with the verb and the thing: Save task, not OK.

Don't

Use a button to navigate (use an <a href>), or put two primary buttons side by side.

Variants

The default is an outline that fills on hover. Primary is filled with the accent at rest. Tone borrows the colours of the tone it sits in; with data-tone="bad" it is a danger button.

Sizes

Every size has a 44px hit area. The small one is drawn at 36px and extends its tappable area invisibly.

With an icon, and as a circle

Icons are masks: <span class="ic ic--plus" aria-hidden="true">. A circle holds one icon and must have an aria-label: a tooltip is not a name.

States

States come from ARIA and native attributes, so the look cannot disagree with what a screen reader is told. The is-* classes below only force a state for this page.

Anatomy

  1. Frame: --bw (2px) in --line. A real border always exists, so forced-colours mode (which deletes fills and shadows) still shows the control.
  2. Fill: --fill mixes the resting colours toward the accent. Rest 0 (outline), hover/pressed 1.
  3. Hard shadow: appears with --lift (4px, zero blur) when the button can be pressed; pressing sinks it back. A shadow means "you can press this".
  4. Label: sentence case, semibold, verb first, 1–3 words.
  5. Icon (optional): 20px mask, decorative when a label is present.
  6. Hit area: an invisible ::after that guarantees 44×44px.

API

Button attributes
AttributeValuesEffect
class="btn"The button. Works on <button> and <a>.
data-variantprimary, tone (default: secondary)Emphasis. Tone reads --tone-bg/ink/fill/on-fill from data-tone on the button.
data-sizesm (36), lg (56) (default 44)Drawn height. The hit area is always at least 44.
data-shapecircleSquare box for one icon. Needs aria-label.
data-blockFull width.
aria-pressedtrue | falseToggle. On = filled AND a doubled frame, so it never depends on the accent being dark.
aria-busy="true"Spinner (a pulse under reduced motion); ignores taps. Announce the result with SG.announce().
disabled / aria-disabled="true"Dashed frame, faint ink, no shadow. Prefer aria-disabled plus a reason in aria-describedby: it stays focusable so people can find out why. SG makes it inert for keyboard too.

Accessibility

Button keyboard and screen reader behaviour
InteractionBehaviour
TabMoves focus to and from the button. The ring (3px, offset 3px) plus a paper halo stays visible on every background.
Enter / SpaceActivates. Native <button> gives this for free; never use a <div>.
Screen reader"Label, button". Toggles add pressed / not pressed; busy adds busy; aria-disabled adds unavailable.
Touch44×44px minimum hit area. No gesture required.
Zoom / text sizeHeights and padding are rem; labels wrap rather than clip at 200% text.
Reduced motionNo lift travel; the fill change stays. The spinner pulses instead of rotating.
Forced coloursThe frame becomes ButtonText; raised and focus get a 4px Highlight outline; on gets a 4px frame.
